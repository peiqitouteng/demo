# 分诊标签（Triage Labels）

各技能都用五个规范的分诊角色来表述。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义                                     |
| -------------------------- | ----------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`          | 维护者需要评估这个 issue                 |
| `needs-info`               | `needs-info`            | 等待报告者补充信息                       |
| `ready-for-agent`          | `ready-for-agent`       | 已完整定义，可以交给 AFK agent           |
| `ready-for-human`          | `ready-for-human`       | 需要人工实现                             |
| `wontfix`                  | `wontfix`               | 不会处理                                 |

当某个技能提到某个角色时（例如“应用 AFK-ready 分诊标签”），就使用本表中右侧对应的标签字符串。

如果本仓库实际使用的是别的命名，直接修改右侧一列即可。
